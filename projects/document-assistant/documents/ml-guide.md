# Machine learning guide

Data leakage occurs when information unavailable at prediction time enters training. Split data before fitting preprocessing. Fit scalers and imputers only on the training partition.

Retrieval-augmented generation (RAG) retrieves relevant document passages and supplies them to a language model. Source citations help readers verify an answer, but citations alone do not guarantee factual correctness.

Precision measures how many predicted positives are correct. Recall measures how many actual positives are found. Use precision-recall metrics for imbalanced classification tasks.
